# Gün 2 – Stil Denemesi Komutları

Aynı sahne (Zuzu + roket + Mars), 3 stil × 3 araç = 9 görsel.
Araçlar: Google Gemini, ChatGPT, Leonardo.ai (ücretsiz katmanlar).
Görseller `docs/style_tests/` klasörüne şu adlarla kaydedilir: `stil1_gemini.png`, `stil1_chatgpt.png`, `stil1_leonardo.png`, `stil2_...`, `stil3_...`

Not: Bu görseller sadece stil seçimi içindir, oyuna girmez. Oyuna girecek görseller için seçilen aracın ticari kullanım şartları ayrıca kontrol edilip `lisanslar.md`'ye yazılır.
