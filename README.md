# Zuzu in Space (ZiS)

5–10 yaş için uzay temalı mobil oyun. Zuzular adlı küçük uzaylı türünün her yeni nesli, kendi tasarladığı roketle gerçek gezegen koşullarına göre hazırlanmış parkurları geçer; ortama uyan özellikler sonraki nesle aktarılır.

- Motor: Godot 4.7.2 (standart sürüm), GDScript
- Platform: önce Android, sonra iOS
- İnternetsiz çalışır, veri toplamaz, reklam içermez

## Klasörler

| Klasör | İçerik |
| --- | --- |
| `scenes/` | Sahneler: main, ui, levels, actors |
| `scripts/` | Kodlar: autoload, actors, systems, ui |
| `assets/` | Modeller, dokular, arayüz, yazı tipleri, sesler |
| `data/` | Gezegen, roket parçası ve özellik ayar dosyaları |
| `levels/` | Dünya, Ay, Mars parkurları |
| `localization/` | Türkçe ve İngilizce çeviriler |
| `docs/` | Kurulum rehberi, kararlar, kaynaklar, lisanslar |

Kurulum için: `docs/setup_guide.md`
